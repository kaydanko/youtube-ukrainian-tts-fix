## 🎯 Глобальна мета

Автоматичний дубляж YouTube відкрив українськомовній аудиторії мільйони відео. Але сьогодні український синтезатор мовлення **систематично ставить хибні наголоси**: «во́да» замість «вода́», «сто́ли» замість «столи́», «по́милка» замість «поми́лка».

Причина — не в складності мови, а в **відсутності якісних конфігурацій словоформ**. Українська має вільний і рухомий наголос: він не прив'язаний до певного складу й може змінюватися залежно від відмінка та числа (*вода́ → во́ди*, *рука́ → ру́ки*). Без явного лексикону модель вгадує — і часто вгадує неправильно, зокрема під впливом російськомовних даних у навчальних корпусах.

**Цей репозиторій існує, щоб:**

- ✅ зібрати **відкритий, перевірений спільнотою** словник словоформ з нормативними наголосами;
- ✅ подати його у **машиночитному форматі**, який інженери можуть інтегрувати за години, а не місяці;
- ✅ зробити виправлення **безкоштовним і універсальним**: одна зміна на боці Google — і правильну вимову чують усі глядачі, без розширень, плагінів чи налаштувань.

> ℹ️ Це незалежна ініціатива спільноти. Проєкт не пов'язаний з Google LLC чи YouTube і не має їхнього схвалення.

## ⚙️ Як це працює

Ми краудсорсимо словник, у якому кожна словоформа зіставляється з **жорстко зафіксованим правильним наголосом** і з **відомими хибними варіантами**, які сьогодні видає синтезатор.

```
 Текст субтитрів / перекладу
            │
            ▼
 ┌──────────────────────────┐
 │  Токенізація + морфологія │  ← визначаємо відмінок, число, рід
 └──────────────────────────┘
            │
            ▼
 ┌──────────────────────────┐
 │   standard_lexicon.json   │  ← шукаємо словоформу (+ граммеми для омографів)
 └──────────────────────────┘
            │
            ▼
   «води» + Gen.Sg  →  води́        «води» + Nom.Pl  →  во́ди
            │
            ▼
       TTS-модель вимовляє правильно ✅
```

**Ключові принципи:**

| Принцип | Що це означає |
|---|---|
| **Словоформа, а не лема** | Наголос фіксується для кожної форми окремо: *стола́*, *столи́*, *столі́в*. |
| **Дві нотації** | Кожен наголос подано і великою літерою (`водА`), і комбінованим знаком U+0301 (`вода́`) — обирайте те, що підтримує ваш рушій. |
| **Хибні варіанти явно** | Поле `incorrect_variants` документує помилки, які ми реально чуємо в дубляжі, — це готові тест-кейси для регресії. |
| **Омографи під контролем** | Форми з однаковим написанням і різним наголосом (*води́ / во́ди*) позначено `homograph: true` і розрізняються за граммемами. |
| **Нормативні джерела** | Кожен запис має відповідати чинним словникам (Орфоепічний словник, СУМ-20, Правопис 2019). |
| **Автоматична звірка** | Кожну наголошену форму звірено з відкритим словником [ukrainian-word-stress](https://github.com/lang-uk/ukrainian-word-stress) (lang-uk, MIT; дані походять зі «Словників України» ULIF). Дані звідти не копіюються: словник використовується лише для пошуку помилок. |

## 🧬 Структура словника

Репозиторій містить **два файли** (UTF-8, NFC):

| Файл | Одиниця запису | Що туди потрапляє |
|---|---|---|
| [`fixed_stress_lexicon.json`](fixed_stress_lexicon.json) | **лема** | Слова, у яких наголос **ніколи не змінюється**: в усіх формах він на тому самому складі (*шко́ла → шко́ли → шкі́л*, *чита́ти → чита́ю → чита́ла*). |
| [`verb_paradigms.json`](verb_paradigms.json) | **повна парадигма дієслова** | Дієслова, у яких наголос **рухається між формами** (*ходи́ти → хо́диш*, *писа́ти → пи́шеш*, *дава́ти → даємо́*): усі 15 форм від інфінітива до дієприслівника. |
| [`standard_lexicon.json`](standard_lexicon.json) | **словоформа** | Слова з **рухомим** наголосом (*вода́ → во́ди*), омографи (*за́мок / замо́к*) і окремі форми, що потребують явного запису. |

Якщо токен є в кількох файлах, пріоритет такий: `standard_lexicon.json` → `verb_paradigms.json` → `fixed_stress_lexicon.json`.

### `fixed_stress_lexicon.json` — сталий наголос

```json
{
  "id": "ukf-0002",
  "lemma": "школа",
  "pos": "NOUN",
  "lemma_features": {"gender": "Fem"},
  "paradigm": "declinable",
  "status": "seed",
  "stressed": {"uppercase": "шкОла", "combining": "шко\u0301ла"},
  "stress_char_index": 2,
  "stress_syllable": 1,
  "syllable_count": 2,
  "sample_forms": [
    {"uppercase": "шкОли", "combining": "шко\u0301ли"},
    {"uppercase": "шкІл", "combining": "шкі\u0301л"}
  ]
}
```

**Головне правило файлу:** у **будь-якій** формі леми наголос падає на голосний номер `stress_syllable`, якщо рахувати від початку слова. Правило не порушують чергування (*шко́ла → шкі́л*, *папі́р → папе́ру*) і випадні голосні після наголосу (*ра́нок → ра́нку*).

| Поле | Опис |
|---|---|
| `paradigm` | `declinable` (іменник), `adjective`, `conjugable` (дієслово), `indeclinable` (*кафе́, метро́*), `invariable` (прислівник, прийменник, сполучник). |
| `stress_syllable` | Номер наголошеного складу. **Саме він чинний для всіх форм.** |
| `sample_forms` | Контрольні форми, у яких наголос найчастіше «стрибає»: Н. і Р. відм. мн. для іменників; 1 і 2 ос. однини, 1 ос. множини та мин. ч. жін. р. для дієслів. Кожну перевірено автоматично. |
| `note` | *(необов'язкове)* Пояснення: чому запис `deprecated`, або що слова немає в довідковому словнику і наголос треба перевірити вручну. |

> ⚠️ Лема, у якої наголос зміщується **хоча б в одній** формі, сюди не потрапляє. Наприклад, *пі́сня → пісні́, пісе́нь*, *ка́зка → казо́к*, *мі́сяць → місяці́*, *ха́та → хати́*. Сюди ж належать дієслова з наголосом на закінченні в 1 і 2 особі множини (*лежа́ти → лежимо́*, *сиді́ти → сидимо́*), назви й імена, у яких наголос зміщується в кличному відмінку (*Литва́ → Ли́тво*, *Петро́ → Пе́тре*), та імена з рухомим наголосом у множині (*Дени́с → Дениси́*). Якщо форма має два нормативні варіанти і один із них відповідає правилу, лема лишається у файлі з поясненням у `note`: наприклад, кличний відмінок *Дніпре́ / Дні́пре* від *Дніпро́*. Такі слова належать до `standard_lexicon.json`.

### `verb_paradigms.json` — наголос у дієсловах

Синтезатори найчастіше помиляються саме в дієсловах: ставлять наголос на префікс (*за́водите* замість **заво́дите**) або переносять наголос інфінітива на всі форми (*ходи́ш* замість **хо́диш**). Тому кожне дієслово перевірено **у всіх формах**: інфінітив, 6 осіб теперішнього (майбутнього) часу, 4 форми минулого, 3 форми наказового способу і дієприслівник.

| Правило | Приклад |
|---|---|
| Недоконані дієслова з префіксом мають сталий наголос **на корені**, а не на префіксі | *заво́дити → заво́джу, заво́диш, заво́дите, заво́див, заво́дь* (у `fixed_stress_lexicon.json`) |
| Доконані дієслова з префіксом **ви-** мають наголос **на ви́-** в усіх формах | *ви́йти, ви́йду, ви́йшла; ви́рішити, ви́рішимо* |
| Те саме написання може означати різні дієслова з різним наголосом | *виво́дити* (недок.) / *ви́водити* (док.), *перехо́дити / переходи́ти*, *пла́чу* (плакати) / *плачу́* (платити) |
| Безпрефіксні дієслова 2-ї дієвідміни: 1-ша особа та інфінітив — на закінченні, інші особи — на основі | *ходи́ти: ходжу́, хо́диш, хо́дить, хо́димо, хо́дите, хо́дять; ходи́в; ходи́; хо́дячи* |
| *-сати / -зати* та їхні префіксальні доконані | *писа́ти: пишу́, пи́шеш; сказа́ти: скажу́, ска́жеш, сказа́вши* |
| *-ува́ти / -юва́ти* | *працюва́ти: працю́ю, працю́єш, працюва́в, працю́й* |
| *-дава́ти / -става́ти / -знава́ти*: у 1 і 2 особі множини та в дієприслівнику — на закінченні | *дава́ти: даю́, дає́ш, **даємо́, даєте́**, даю́ть, дава́в, дава́й, **даючи́*** |
| Наголос на закінченні в усіх формах | *коти́ти: кочу́, коти́ш, **котимо́**, котя́ть, котячи́* |
| Зворотні дієслова: *-ся/-сь* **ніколи** не наголошується, наголос такий самий, як у формах без *-ся*; записано обидва варіанти закінчення | *диви́тися: дивлю́ся / дивлю́сь, ди́вишся, ди́виться, диви́вся, диви́сь, ди́влячись*; *займа́тися: займа́юся, займа́ється* |
| Префікси *по-* / *про-* зі значенням «трохи, певний час» переносять наголос на корінь | *стоя́ти* → **посто́яти**, *посто́ю*; *сиді́ти* → **поси́діти**, *поси́джу*; *лежа́ти* → **поле́жати**; *мовча́ти* → **помо́вчати** |
| Префіксальні доконані від неправильних дієслів мають наголос базового дієслова | *перенести́: перенесу́, перенесе́ш, переніс, перенесла́, перені́сши; забра́ти: заберу́, забере́ш, забра́ла* |
| Неправильні дієслова записано вручну форма за формою | *бу́ти: бу́ду, був, була́; іти́: іду́, ідемо́, ішо́в; піти́: піду́, **пі́деш**; ї́сти: їм, їси́, їдя́ть; взя́ти: візьму́, ві́зьмеш, взя́ла; бра́ти: беру́, бра́ла* |

```json
{
  "id": "ukv-0001",
  "lemma": "ходити",
  "pos": "VERB",
  "lemma_features": {"aspect": "Imp"},
  "conjugation": "2",
  "stress_pattern": "mobile",
  "status": "seed",
  "forms": [
    {"slot": "inf", "form": "ходити", "grammemes": {"verb_form": "Inf"}, "stressed": {"uppercase": "ходИти", "combining": "ходи\u0301ти"}},
    {"slot": "1sg", "form": "ходжу", "grammemes": {"verb_form": "Fin", "tense": "Pres", "person": "1", "number": "Sing"}, "stressed": {"uppercase": "ходжУ", "combining": "ходжу\u0301"}},
    {"slot": "2sg", "form": "ходиш", "grammemes": {"verb_form": "Fin", "tense": "Pres", "person": "2", "number": "Sing"}, "stressed": {"uppercase": "хОдиш", "combining": "хо\u0301диш"}}
  ]
}
```

Поля `homograph: true` (таке саме написання є в іншого слова з іншим наголосом) та `attested: false` (форми немає в довідковому словнику) показують, де потрібна обережність. Дієслова зі **сталим** наголосом лишаються у `fixed_stress_lexicon.json`. Кожне з них теж перевірено за всіма формами, які вдалося згенерувати.

### `standard_lexicon.json` — словоформи

```json
{
  "id": "uk-0001-02",
  "form": "води",
  "grammemes": {"case": "Gen", "number": "Sing"},
  "stressed": {"uppercase": "водИ", "combining": "води́"},
  "stress_char_index": 3,
  "stress_syllable": 2,
  "syllable_count": 2,
  "incorrect_variants": [{"uppercase": "вОди", "combining": "во́ди"}],
  "homograph": true,
  "context_hints": {"disambiguate_by": "grammemes", "preceding_tokens": ["без", "до", "склянка"]},
  "example": "Склянка води́."
}
```

| Поле | Тип | Опис |
|---|---|---|
| `id` | string | Стабільний ідентифікатор `uk-NNNN-NN` (лема + форма). Ніколи не перевикористовується. |
| `form` | string | Словоформа в нижньому регістрі без знаків наголосу — **ключ пошуку**. |
| `grammemes` | object | Граматичні ознаки у форматі Universal Dependencies v2 (`case`, `number`, `gender`, `tense`, `verb_form`…). |
| `stressed.uppercase` | string | Наголошений голосний — велика літера. |
| `stressed.combining` | string | Знак `U+0301` одразу після наголошеного голосного. |
| `stress_char_index` | int | Позиція наголошеного голосного у `form` (з 0, у кодових точках Unicode). |
| `stress_syllable` | int | Номер наголошеного складу (з 1). |
| `incorrect_variants` | array | Хибні наголоси, які трапляються в TTS. |
| `homograph` | bool | `true`, якщо існує інша форма з тим самим написанням і іншим наголосом. |
| `sense` | string | *(необов'язкове)* Коротка англійська глоса для лексичних омографів з однаковими граммемами: `castle` / `lock` для *за́мок / замо́к*. |
| `context_hints` | object | Евристичні підказки для омографів (запасний варіант, не правило). `disambiguate_by` вказує, чим розрізняти: `grammemes`, `pos`, `aspect` або `sense`. |

| `status` / `note` | Статус леми (словоформа може мати власний `status`, який його перевизначає) і пояснення рішення. |

**Статуси записів:**

| Статус | Значення | Застосовувати? |
|---|---|---|
| `seed` | Початковий запис, звірений із джерелами; чекає незалежної перевірки. | ✅ |
| `verified` | Підтверджено щонайменше двома рецензентами з посиланням на джерело. | ✅ |
| `disputed` | Нормативні джерела розходяться (наприклад, ULIF дає *ки́дати*, а класичні орфоепічні списки — *кида́ти*). Потрібне рішення лінгвіста. | ❌ |
| `deprecated` | Запис збережено для відстежуваності, бо `id` не перевикористовуються. | ❌ |

### 📊 Що вже є у словниках

**`fixed_stress_lexicon.json` v0.11.0 — 4777 лем зі сталим наголосом** (2193 загальні іменники, 616 власних назв, 945 прикметників і дієприкметників, 645 дієслів, 378 незмінних слів), 5584 контрольні форми. Понад 43 000 форм іменників звірено зі словником ULIF. **Кожен прикметник перевірено за всіма 13–14 формами**: рід, число, відмінок, разом 13 187 форм. Дієслова перевірено за всіма формами, які вдалося згенерувати. Дев'ять записів мають статус `deprecated`. Серед них *Петро, Дмитро* (наголос зміщується в кличному відмінку) і сім дієслів на *-давати / -ставати*: у них наголос зміщується в *даємо́, даєте́, даючи́*, тож вони перенесені до `verb_paradigms.json`. 36 слів, яких немає в ULIF, мають примітку про ручну перевірку.

**`verb_paradigms.json` v0.3.0 — 571 дієслово, 8779 форм.** Це рухомі дієслова (*ходи́ти, роби́ти, писа́ти, сказа́ти, купува́ти, працюва́ти, дава́ти, коти́ти…*), 139 неправильних і похідних від них (*бу́ти, іти́, піти́, ї́сти, хоті́ти, могти́, нести́ → перенести́, відвести́, перекла́сти, прибі́гти, прожи́ти, забра́ти, відібра́ти…*), понад 200 префіксальних доконаних (*перероби́ти, розкрути́ти, переговори́ти, підказа́ти, проаналізува́ти, перебудува́ти, нагодува́ти…*), зворотні з рухомим наголосом (*диви́тися, учи́тися, зупини́тися, поверну́тися…*) і 39 недоконаних, що мають двійника з тим самим написанням. Кожну форму звірено зі словником ULIF, у ньому немає лише 27 форм.

### 2. Побудова таблиці пошуку (Python)

```python
import json
import unicodedata
from collections import defaultdict

SKIP = {"deprecated", "disputed"}   # такі записи не застосовуються

with open("standard_lexicon.json", encoding="utf-8") as f:
    lexicon = json.load(f)

# form -> список кандидатів (більше одного лише для омографів)
lookup = defaultdict(list)
for entry in lexicon["entries"]:
    if entry["status"] in SKIP:
        continue
    for wf in entry["wordforms"]:
        if wf.get("status") in SKIP:
            continue
        lookup[wf["form"]].append({
            "lemma": entry["lemma"],
            "pos": entry["pos"],
            "grammemes": wf["grammemes"],
            "combining": wf["stressed"]["combining"],
            "uppercase": wf["stressed"]["uppercase"],
            "homograph": wf["homograph"],
        })

# --- Дієслова з рухомим наголосом: кожна форма парадигми (нижчий пріоритет, ніж standard_lexicon) ---
with open("verb_paradigms.json", encoding="utf-8") as f:
    for entry in json.load(f)["entries"]:
        if entry["status"] in SKIP:
            continue
        for wf in entry["forms"]:
            if any(c["lemma"] == entry["lemma"] for c in lookup.get(wf["form"], [])):
                continue
            lookup[wf["form"]].append({
                "lemma": entry["lemma"],
                "pos": "VERB",
                "grammemes": wf["grammemes"],
                "combining": wf["stressed"]["combining"],
                "uppercase": wf["stressed"]["uppercase"],
                "homograph": wf.get("homograph", False),   # позначено саме ті форми, що мають двійника
            })

def stress(token: str, grammemes: dict | None = None) -> str:
    """Повертає токен з наголосом U+0301 або без змін, якщо словоформи немає."""
    key = unicodedata.normalize("NFC", token.lower())
    candidates = lookup.get(key)
    if not candidates:
        return token
    if len(candidates) > 1 or candidates[0]["homograph"]:  # омограф: потрібні граммеми з аналізатора
        if grammemes is None:
            return token     # не вгадуємо — краще без змін, ніж хибний наголос
        candidates = [c for c in candidates
                      if all(grammemes.get(k) == v for k, v in c["grammemes"].items())]
        if len(candidates) != 1:
            return token
    stressed = candidates[0]["combining"]
    return stressed[0].upper() + stressed[1:] if token[:1].isupper() else stressed

print(stress("Вода"))                                    # Вода́
print(stress("води", {"case": "Gen", "number": "Sing"})) # води́
print(stress("води", {"case": "Nom", "number": "Plur"})) # во́ди
print(stress("пишеш"), stress("ходите"), stress("даємо")) # пи́шеш хо́дите даємо́
print(stress("дивишся"), stress("підеш"), stress("візьмемо"))  # ди́вишся пі́деш ві́зьмемо

# --- Леми зі сталим наголосом: потрібна лема та частина мови з вашого лематизатора ---
with open("fixed_stress_lexicon.json", encoding="utf-8") as f:
    fixed = {(e["lemma"].lower(), e["pos"]): e["stress_syllable"]
             for e in json.load(f)["entries"] if e["status"] not in SKIP}

VOWELS = set("аеєиіїоуюяАЕЄИІЇОУЮЯ")

def stress_fixed(token: str, lemma: str, pos: str) -> str:
    """Ставить наголос на склад stress_syllable у будь-якій формі леми."""
    n = fixed.get((lemma.lower(), pos))
    if n is None or stress(token) != token:   # пріоритет — у standard_lexicon.json
        return token
    seen = 0
    for i, ch in enumerate(token):
        if ch in VOWELS:
            seen += 1
            if seen == n:
                return token[:i + 1] + "\u0301" + token[i + 1:]
    return token

print(stress_fixed("школи", "школа", "NOUN"))     # шко́ли
print(stress_fixed("шкіл", "школа", "NOUN"))      # шкі́л
print(stress_fixed("читаємо", "читати", "VERB"))  # чита́ємо
print(stress_fixed("заводите", "заводити", "VERB"))  # заво́дите
print(stress_fixed("спантеличені", "спантеличений", "ADJ"))  # спантели́чені
print(stress_fixed("Києві", "Київ", "PROPN"))     # Ки́єві
```

### 3. Рекомендації з інтеграції

- **Порядок застосування:** токенізація → морфологічний аналіз (граммеми) → пошук у лексиконі → передача тексту з `U+0301` (або у вашому форматі фонем) у TTS.
- **Пріоритет:** записи лексикону мають перевизначати передбачення моделі наголосу (stress predictor) для відповідних словоформ.
- **Омографи:** застосовуйте лише після морфологічного розрізнення. `context_hints` — запасна евристика.
- **Сталий наголос:** `fixed_stress_lexicon.json` застосовується до **леми**. Однакове написання ще не означає ту саму лему: *плачу* — це і *пла́чу* (від «плакати»), і *плачу́* (від «платити»). Тож без лематизатора правило застосовуйте лише до записів `indeclinable` та `invariable`.
- **Статуси:** записи `disputed` і `deprecated` (на рівні леми чи словоформи) не застосовуйте.
- **Прикметники та дієприкметники:** наголос ніколи не зміщується між формами. *Спантели́чений → спантели́чені, спантели́ченого, спантели́ченою*, як і *пора́нений → пора́нені*. У дієприкметниках наголос не завжди такий, як в інфінітиві: *прочита́ти → прочи́таний*, *прода́ти → про́даний*, *організува́ти → організо́ваний*. Тому їх записано окремо.
- **Дієслова:** не переносьте наголос інфінітива на інші форми. У дієсловах із `verb_paradigms.json` він рухається: *ходи́ти → хо́диш*, *дава́ти → даємо́*. Також не ставте наголос на префікс недоконаних дієслів: правильно *заво́дите, прино́сите, перево́дите*. Виняток — доконані дієслова з *ви́-*: *ви́йдете, ви́рішите*.
- **Нотація:** якщо ваш рушій не приймає `U+0301`, використовуйте `stress_char_index` / `stress_syllable` для генерації SSML `<phoneme>`, PLS (W3C Pronunciation Lexicon Specification) або власного формату.
- **Регресійні тести:** кожен елемент `incorrect_variants` — готовий негативний тест-кейс: вихід синтезатора не повинен з ним збігатися.
- **Нормалізація апострофа:** `'`, `’` (U+2019) і `ʼ` (U+02BC) слід зводити до одного символу перед пошуком.

### 4. Зворотний зв'язок

Якщо вам потрібне інше поле, формат експорту (CSV, PLS, TSV) або зміна схеми — відкрийте Issue. Ми адаптуємо формат під реальні потреби пайплайну.
